# Privacy policy draft (not legal advice)

NexaShare is designed to work without accounts and without sending your files to NexaShare operators. Local transfers stay on your network.

## Data we do not collect by default

- No telemetry
- No advertising identifiers
- No cloud file copies
- No analytics SDK

## Data stored on the device

- Display name you choose
- TLS certificate and key for this installation
- Paired-device fingerprints and session tokens
- Transfer history (names, sizes, states)
- Destination folder path

You can unpair devices and clear history from the app.

## Network

Discovery broadcasts a random device id, display name, protocol version, port, capabilities, and certificate fingerprint on the local multicast group. It does not broadcast file names or contents.
